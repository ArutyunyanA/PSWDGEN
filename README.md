### Passwords generator CLI utility for command prompt generating passwords and saving it to the .txt file.

## Step 1: Downloading.

```bash
git clone https://github.com/ArutyunyanA/PSWDGEN.git
cd PSWDGEN
```
## Step 2: Installation.

```bash
cargo install --path .
```
